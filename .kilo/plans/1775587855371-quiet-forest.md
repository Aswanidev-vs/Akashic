# Akashic - Additional Features Plan

## Project Overview
Akashic is a Notepad alternative with local AI (Ollama) integration built with Wails (Go + vanilla JS frontend).

---

## Suggested Additional Features

### High Priority Features

#### 1. Command Palette (Ctrl+Shift+P)
- Modal dialog for quick command access
- Search through all menu actions
- Fuzzy search matching
- Recently used commands
- Keyboard-driven workflow

#### 2. Auto-Save
- Periodic auto-save (configurable interval: 30s, 1min, 5min)
- Auto-save to temp location for crash recovery
- Option to disable auto-save
- Notification on auto-save

#### 3. Multiple File Support
- Drag and drop files to open
- Open multiple files at once
- Recent files panel in sidebar
- File tabs reordering (drag and drop)

#### 4. Advanced Search/Replace
- Search across all open tabs
- Find in files (directory search)
- Replace all in current file
- Match case toggle
- Regex support (partially exists, could enhance)

#### 5. Editor Enhancements
- Code syntax highlighting (for common languages)
- Bracket matching/auto-close
- Auto-indentation
- Multiple cursors
- Find and highlight all occurrences

### Medium Priority Features

#### 6. AI Features Expansion
- AI code completion inline
- AI chat with selected text (context-aware)
- AI prompt templates
- Model management UI (download/delete models)
- AI response streaming toggle

#### 7. File Explorer Sidebar
- Tree view of folders
- Create/delete/rename files
- File icons by type
- Collapse/expand folders

#### 8. Session Restore
- Restore last session on startup
- Remember open tabs and cursor positions
- Remember window size/position
- Remember sidebar state

#### 9. Editor Themes
- Additional syntax highlighting themes
- Custom theme import
- Theme preview

#### 10. Markdown Preview
- Live preview for .md files
- Toggle between edit/preview/split view
- GitHub-flavored markdown support

### Lower Priority Features

#### 11. Split View
- Split editor horizontally or vertically
- View different files or same file
- Resizable split panels

#### 12. Bookmarks
- Add/remove bookmarks on lines
- Bookmark navigation panel
- Persist bookmarks with file

#### 13. File Comparison
- Diff view between two files
- Side-by-side comparison

#### 14. Export Options
- Export as HTML
- Export as Markdown
- Export with syntax highlighting

#### 15. Customizable Keyboard Shortcuts
- Shortcut customization UI
- Import/export shortcuts

---

## Implementation Recommendation

**Start with:**
1. Command Palette (high impact, moderate effort)
2. Auto-Save (high impact, low effort)
3. Session Restore (high impact, low effort)

**Then:**
4. File Explorer sidebar
5. Code syntax highlighting
6. Markdown preview

**Later:**
7. Split view
8. File comparison
9. Customizable shortcuts
